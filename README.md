# PowerGrid-Nexus

A lightweight **Power Plant Simulator** built entirely with HTML, JavaScript, and powered by [Neutralinojs](https://neutralino.js.org/).

---

## Features

* **Real-time Grid Management:** Control power generation output and maintain grid stability.
* **Lightweight Desktop App:** Native desktop experience powered by Neutralinojs with minimal RAM and CPU usage.
* **Pure Web Tech:** Built using standard HTML, CSS, and vanilla JavaScript.

---
